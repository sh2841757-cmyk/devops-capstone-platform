# Terraform section

This capstone includes an infrastructure-as-code design exercise. To keep the default
project free of cloud charges, the core deployment uses Docker Compose and local
Kubernetes.

For assessment, document a proposed cloud architecture (VPC, private/public subnets,
security groups, compute, monitoring) and create a Terraform plan in a separate
sandbox account only if you understand the provider's billing. Do not run `terraform
apply` against paid resources without approval. Include `terraform fmt`, `validate`,
and `plan` output in your evidence if you add provider-specific configuration.
