# Demo and evidence checklist

Capture genuine screenshots and command output for each item. Mark an item complete only after verification:
- [ ] GitHub repository with README and source tree
- [ ] Successful GitHub Actions test run
- [ ] Successful Docker image build
- [ ] `docker compose ps` showing app, Prometheus, Grafana
- [ ] Browser/API response from `/health`
- [ ] Prometheus target showing the app as UP
- [ ] Grafana connected to Prometheus and displaying metrics
- [ ] Kubernetes pods and service (if a local cluster is available)
- [ ] Ansible playbook run output
- [ ] Project report and architecture diagram

Do not fabricate screenshots or claim a stage passed until you have run it.
